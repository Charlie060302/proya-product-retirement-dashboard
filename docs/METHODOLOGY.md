# 商品汰换决策模型与数据边界

## 1. 业务问题

项目材料显示，珀莱雅官旗即时零售采用自产自销试点，经营目标是在扩大销售的同时控制投入成本。商品管理的核心矛盾不是“卖得少就下架”，而是如何在品类差异、毛利贡献、库存占用、新品培育及门店分布之间建立可复核的优先级。

美团闪购·品牌通公开介绍了品牌经营沙盘、商品供给决策、品牌商品管理等能力，说明品牌侧即时零售需要同时管理交易、供给与商品信息。该公开资料只用于行业背景，不能证明本项目使用了相同接口或系统。

## 2. 数据粒度与汇总规则

真实项目原表5,747行。看板对商品名称、商品编码、销量及可选经营字段进行字段映射与数值校验，形成4,211条有效门店×SKU记录，覆盖142家门店、122个SKU与14个品类。

以商品编码作为SKU主键，商品层汇总规则如下：

| 指标 | 汇总方式 |
| --- | --- |
| 销量 | 商品在全部有效门店的销售件数求和 |
| 销售额 | 商品在全部有效门店的商品收入求和 |
| 毛利额 | 商品在全部有效门店的商品毛利求和 |
| 毛利率 | 汇总毛利额 ÷ 汇总销售额；销售额为0时使用可用明细回退 |
| 库存量 | 商品在全部门店的有效库存量求和，包括零销量但有库存的门店 |
| 库存金额 | 商品在全部门店的有效库存金额求和 |
| 有销量门店数 | 仅统计该商品销量大于0的门店 |

门店销量下钻只展示有实际销售的门店；零销量但持有库存的门店不计入“有销量门店数”，但其库存量与库存金额必须计入商品总库存。

## 3. 同品类Min-Max风险标准化

不同品类的价格带、购买频次和毛利结构不同，因此模型优先在同品类内比较。对指标 `x` 的正向风险标准化为：

```text
高值越差：Risk(x) = (x - min) / (max - min)
低值越差：Risk(x) = 1 - (x - min) / (max - min)
```

毛利率、销售额和销量采用“低值越差”；库存金额采用“高值越差”。当品类只有少量SKU时，分布不稳定，因此同品类样本少于3个时使用全局分布辅助计算，但不直接输出汰换结论。缺失指标使用中性风险0.5，避免静默按0处理。

Min-Max保留相对距离，解释直观，但对极端值敏感。因此本项目不把指数作为唯一判定依据，而是在指数之后增加中位数门槛和业务保护规则。

## 4. 汰换指数

默认权重为：

```text
Score = 100 × (
  0.35 × Risk(低毛利率) +
  0.25 × Risk(低销售额) +
  0.25 × Risk(低销量) +
  0.15 × Risk(高库存金额)
)
```

权重合计自动归一化。毛利率权重最高，是因为项目需要优先控制对利润空间的侵蚀；销售额和销量分别衡量金额贡献与动销强度；库存金额反映资金占用，但不应覆盖商品的收入和利润贡献。

每个SKU同时保留四项风险分及前两项主要拖累，用于解释“为什么分数高”。指数是排序分，不是下架概率。

## 5. 三档判定逻辑

### 汰换候选

同时满足：

1. 销量低于同品类中位数；
2. 毛利率低于同品类中位数；
3. 汰换指数≥70；
4. 品类样本不少于3个且不是“其他/未分类”；
5. 销售额和毛利额均未达到同品类中位数；
6. 非新品。

### 引流/观察

出现单项短板且指数≥50，或销量处于极低水平（不高于同类中位数25%，且最多2件）时进入观察。满足汰换分数但触发小样本、未分类或贡献保护的商品也降级为观察。

### 保留

指数低于50，或毛利率与销量均未落入风险区的商品保留。新品进入培育期豁免，不与成熟商品直接比较。

将70设为汰换线是业务规则，不是统计显著性阈值。它需要结合历史回测、不同品类误判成本和业务复核结果持续校准。

## 6. 贡献保护与稳健性

- **贡献保护：**销售额或毛利额达到同类中位数，说明商品仍有金额贡献，即使综合指数较高也不直接汰换。
- **新品保护：**新品缺少完整观察期，暂不进入成熟商品汰换比较。
- **小样本保护：**同品类少于3个SKU时，不根据不稳定分布直接下结论。
- **未分类保护：**“其他/未分类”中的商品不可假设互相可比。
- **极低动销规则：**高毛利率不能掩盖几乎无销量的事实，这类商品至少进入观察。

## 7. 动销率与覆盖率

看板中的动销率定义为：

```text
动销率 = 有效记录销量总和 ÷（有效记录销量总和 + 有效记录库存量总和）
```

只纳入销量与库存量均为有限非负数的门店×SKU记录。有效库存量记录覆盖率低于80%时，动销率标记为“仅供参考”，避免把缺失库存误当成0而虚高结果。库存金额不能替代库存量。

## 8. 样本分析结果

在默认权重和规则下：

- 12个汰换候选，占122个SKU的9.8%；
- 57个引流/观察商品；
- 53个保留商品；
- 候选销售额占比2.8%，毛利额占比1.7%；
- 候选库存金额约1.82万元，占总库存金额4.1%。

这些结果支持确定复核优先级，不能直接写成已实现资金释放。正式下架前还需核对替代品、关联销售、套装父子关系、活动排期、合同与供应链约束。

## 9. 公开演示边界

公开看板使用20个模拟SKU和4家模拟门店，商品编码均以 `DEMO-` 开头。真实Excel、真实商品清单和门店明细不公开。模拟样本用于展示筛选、评分、气泡定位、门店下钻和Excel导出流程，不用于证明真实经营结果。

## 10. 面试说明示例

“我没有把高分直接等同于下架。先在同品类内用Min-Max把低毛利、低贡献、低销量和高库存转换为风险分，再用35/25/25/15权重做排序。然后加上销量与毛利率双低门槛、同类中位数、高贡献保护、新品和小样本保护，最后才形成三档名单。这样既保留模型的可解释性，也把业务误判成本放进规则里。”
